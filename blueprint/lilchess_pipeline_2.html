🔥 Hot Path Pipeline (Real-time)

Từ Lichess API đến Power BI Dashboard

1. Ingestion Layer
☁️

AWS EC2 (Producer)

realtime_move.py cào dữ liệu từ Lichess API (HTTP Streaming) thông qua ThreadPoolExecutor.

2. Message Broker
🐿️

Confluent Cloud (Apache Kafka)

Trạm trung chuyển dữ liệu Real-time (SASL/SCRAM-SHA-256).

Topic: move Topic: user Topic: game
3. Processing Layer (PySpark Structured Streaming)
⚡

consumer_moves.py

Đọc topic move

Dùng Stockfish UDF tính toán Centipawn Loss, xác định Blunder/Mistake.
👤

consumer_users.py

Đọc topic user

Dùng arrays_zip + explode tách data, tính tỷ lệ thắng win_rate_pct.
♟️

consumer_games.py

Đọc topic game

Format time (epoch to timestamp), chuẩn hóa cờ winner (0/1/-1).
Môi trường tính toán: Google Colab (12GB RAM)
4. Storage Layer (Gold)
🐘

AWS RDS (PostgreSQL)

Lưu trữ dữ liệu đã qua xử lý và phân tích.

Table: fact_moves
Table: dim_users
Table: dim_games
5. Serving Layer
📊

Power BI Desktop (Local Machine)

Kết nối trực tiếp vào AWS RDS (Port 5432). Vẽ Dashboard trực quan phân tích nước đi và publish lên Cloud.
